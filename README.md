# checkboxlabs.com

The website for Checkbox Labs. It is one static HTML page served by GitHub Pages at [checkboxlabs.com](https://checkboxlabs.com).

## Editing

Change `index.html` and push to `main`. GitHub Pages republishes the site within a minute or two. There is no build step.

## Domain

`CNAME` tells GitHub Pages which domain to serve. At the domain registrar, the apex `checkboxlabs.com` has A records for GitHub Pages and `www` has a CNAME to the GitHub Pages host. The mail records (MX and SPF for Zoho) are separate and must not be changed.
